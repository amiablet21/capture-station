Stock — a Cost column, on the computers you choose

One more column on the Stock sheet, carrying each SKU's cost (Linnworks' purchase price). It appears only on stations with the Cost tick in Settings, and only those stations can change it. Every change is a COST line in that SKU's history, with the computer and the before → after, and Cost joins the history's action filter.

With the filter off, COST lines sit in date order among SOLD, WHOLESALE and the rest, same pill shape, amber. The Everyone filter narrows them to one computer as usual. A "Cost now" tile replaces "In · 7 days" on stations with the tick so the current cost and its last change are one glance away. The optional note is asked for when you save a change ("new supplier quote"); Enter with an empty note is fine. Stations without the tick never see COST lines or the tile.

Pages on this station

Capture is always on. Cost shows the Cost column and the cost history on the Stock page; leave it unticked on the packing station.

The cost itself lives in Linnworks as the item's purchase price, so it's one number everywhere and survives reinstalls; the app writes it there and logs the change to the shared stock history. The channel-SKU export gets a Cost column too, but only when exported from a ticked station.
