1 · Stock → Unlisted: pick what to list

The Unlisted view already knows which in-stock SKUs have no Walmart listing. It gains a tick box and a UPC column (Walmart matches on the UPC). Tick the rows, press List on Walmart. Rows with no UPC can still be ticked; the next step asks for it.

3 · Sent: results come back per SKU

All offers go to Walmart in one upload. Walmart takes anywhere from a few minutes to a few hours, so the dialog can be closed. The app keeps checking and shows a toast when the results are in. Problems are shown in plain words with a fix-and-resend for that row only.
